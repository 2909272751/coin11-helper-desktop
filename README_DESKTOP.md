# Coin11 助手（桌面版）使用说明

> 非官方桌面封装。本软件把开源项目 **coin11-tb** 包装为 Windows 10/11 x64 桌面应用。
> 上游源码地址：<https://github.com/czl0325/coin11-tb>（Apache-2.0 许可）。

## 它是什么

一个只在你本机运行的中文桌面程序：

- 用**内置 ADB** 管理通过 USB 连接的安卓设备（无需自己安装 Python、Git、ADB）；
- **实时日志**：任务运行中脚本的每一行输出立即显示在日志区（不等任务退出），
  并保留最近输出用于诊断；支持“自动滚动”与“仅看错误”；
- **断线保护**：运行期间每约 2 秒检查所选设备是否仍在线；设备连续两次
  缺失 / 离线 / 未授权时，自动安全停止当前任务与整个队列，并在界面如实标注；
- 在图形界面里选择任务并运行：**日常任务**（淘宝成就中心签到、闲鱼扔骰子、
  淘宝芭芭农场、淘金币、天猫摇钱树、支付宝农场、淘宝现金签到、闲鱼现金签到、
  支付宝打卡、玩赚支付宝、玻弦打卡），以及可展开的**限时活动**分组（2024 双11、
  2025 618、2025 双11、2026 618，页面可能已改版/过期，运行前会再次确认）；
  任务清单是主窗口的弹性主体，勾选/取消/限时活动工具固定在其下方；
- 可从指定的上游仓库**一键同步最新脚本**，并**保留上一版可回退**；这些低频
  维护项与下载中心、重新检测组件、运行时目录、打开日志目录、复制诊断文本一并
  收纳在顶部 **维护与更新 ▾** 菜单；**设备 ▾** 菜单提供刷新设备、重新接管 ADB
  与设备连接说明；
- **现代毛玻璃感单页界面**：标题品牌区显示应用图标与连接状态，任务、运行控制、
  实时日志集中于单页；实时日志默认折叠为状态条，可展开查看完整日志并使用
  自动滚动 / 仅看错误 / 复制 / 打开目录；
- **两种发行形态**：
  - **完整运行时离线版（0.3.0+）**：运行组件（Python + torch/easyocr 等依赖与
    离线 OCR 模型）全部随发行内置，解压即用、可完全离线运行；
  - **轻量安装版（0.4.0）**：安装包小得多；首次启动后到软件内“下载中心”联网
    下载运行必需组件，安装到 `%LOCALAPPDATA%\Coin11Helper\runtime`（可在界面改
    目录），下载/安装/校验在后台完成、失败可重试，任务运行与完整版一致。

**重要**：本软件不收集、不上传任何账号、屏幕、日志或手机数据；不处理登录、
验证码、支付，也不尝试绕过任何授权。任务脚本正常结束不等于手机上所有真实任务
都成功 —— 是否真的完成，请以手机界面为准。限时活动脚本可能已过期，失败会如实显示。

## 安装

### 轻量安装版（推荐联网首次下载）

1. 双击 `Coin11助手安装版-<version>-windows-x64.exe`，在安装向导中选择安装目录
   （不强制管理员；默认 `%ProgramFiles%\Coin11助手轻量版`，可改），可选创建桌面
   快捷方式，完成安装与卸载注册。
2. 首次启动打开主窗口；任务区旁若出现“缺少运行组件”提示，点击顶部
   **维护与更新 ▾ → 下载中心**，表格列出：Python 基座（随包内置）、自动化
   依赖、图像/OCR 基础、CPU torch、EasyOCR 离线模型（含用途、预估大小、
   状态与下载/重试/取消）。
3. 点 **下载必需组件**：程序自动把内置 Python 3.12 基座复制到运行时目录
   `%LOCALAPPDATA%\Coin11Helper\runtime`，然后按依赖顺序后台下载安装并校验
   （下载失败/中断不会留下“半成品”，校验不通过可一键重试；大体积下载与
   CPU torch 需要一些时间，进度以阶段与组件计数显示）。
4. 全部显示“已就绪”后即可选设备、勾任务、开始运行。

> **存储位置与体积**：运行组件默认装在 `%LOCALAPPDATA%\Coin11Helper\runtime`。
> 全部装齐后解压体积约 **3–5 GB**（含 CPU torch、OpenCV、EasyOCR 模型）；
> 安装包本身仅含桌面壳、ADB、Python 基座，约 **150–250 MB**。
> 重装应用或卸载不会删除该目录（卸载时可勾选“同时删除我的数据”才会清掉）。

> 未联网 / 组件未装齐时，任务会明确提示去下载中心，**不会**用不完整的运行时
> 启动子进程。依赖来源为内置 HTTPS 官方清单（PyPI / PyTorch 官方 CPU wheel /
> EasyOCR 官方模型 release），版本固定，不执行任何远程任意代码。

### 完整运行时离线版（解压即用，体积大）

1. 解压 `Coin11助手-<version>-windows-x64.zip` 到任意目录（例如 `D:\Coin11助手`）。
2. 运行目录里的 `Coin11助手.exe`。
3. 首次启动会自动把出厂脚本复制到用户数据目录
   （`%LOCALAPPDATA%\Coin11Helper\scripts\current`），程序目录只读也能正常运行。
4. 无需安装 Python、Git 或 ADB —— 全部随程序内置。

> **体积说明**：0.2.0/0.3.0 完整运行时发行版内置 CPU 版 PyTorch、OpenCV、EasyOCR
> 及离线中文模型，解压后体积可达 **3–5 GB**（压缩包约 2–3 GB），这是实现完全离线
> 任务运行的必要代价，属预期。若不需要完全离线、愿意首次联网下载，请改用轻量版。

> 杀毒软件若提示，请选择“允许”。应用所有子进程与日志都只在本机。

## 首次连接设备（USB 调试）

首次没有设备时，请按以下四步操作：

1. 手机进入 **设置 → 关于手机**，连续点击 **版本号** 7 次，开启开发者选项；
2. 回到 **设置 → 开发者选项**，打开 **USB 调试**；
3. 用**数据线**（非纯充电线）连接电脑与手机，手机上选择“允许 USB 调试”；
4. 在本应用点击 **刷新设备**。

若提示 `unauthorized`（未授权）：解锁手机屏幕，在授权弹窗勾选
**“始终允许来自此计算机的调试”**，点 **允许**，再点 **刷新设备**。

若设备显示离线（offline）：重新插拔数据线；确认没有其他程序独占 ADB。

## 运行任务

1. 在顶部设备下拉框选择你要操作的设备（同一时间只运行一个设备、一个任务）；
2. 勾选要运行的任务（可“全选日常任务”/取消，限时活动需先点 **显示限时活动**），
   运行顺序即列表顺序；
3. 点 **开始运行**。运行中可点 **停止**（安全停止整个进程树）；
4. 运行状态显示当前任务、已用时与队列进度（如 1/8）；每个任务结束后显示
   **成功 / 失败 / 已停止 / 跳过**；
5. 日志区**实时**显示脚本输出（不等任务退出），可用 **复制诊断文本**、
   **打开日志目录**、“仅看错误”过滤与“自动滚动”开关。

> **断线保护**：任务运行期间每约 2 秒检查所选设备。若设备连续两次检测不到
> （拔线 / 离线 / 未授权），界面会提示“设备已断开，已自动停止任务”，
> 安全停止当前任务进程树，并且**不会继续运行队列里的后续任务**。
> 手动停止或任务正常结束不会被误报为设备断开。
> 设备列表“刷新”与后台断线检查不会互相阻塞 UI。

> **限时活动**：任务清单下方的“限时活动”为历史/季节活动脚本
> （2024 双11、2025 618、2025 双11、2026 618 等），页面可能已改版或活动已结束，
> 运行前会弹出确认，脚本失败会如实显示，请以手机界面为准。

> **运行时说明**：0.2.0–0.3.0 任务由发行内置的 Python 3.12 解释器
> （`runtime\python\python.exe`）运行，全部依赖（torch/easyocr/ddddocr/opencv/
> uiautomator2 等）都在该运行时内；EasyOCR 使用发行内置的离线模型目录
> （`runtime\easyocr-models`），无需联网下载模型。
> **0.4.0 轻量版**改为：运行时解释器与依赖装在用户数据目录
> `%LOCALAPPDATA%\Coin11Helper\runtime\python`（下载中心安装/修复），EasyOCR
> 模型在同目录 `easyocr-models`；任务只使用“已验证的数据运行时解释器”，
> 不会误用只含 pip 的内置基座。若启动任务时报“缺少运行组件”，请打开主界面
> **维护与更新 ▾ → 下载中心**补齐；完整发行目录不完整时请重新解压完整安装包。

## 更新 / 回退脚本

- **同步最新脚本**：点击后从固定上游
  `https://github.com/czl0325/coin11-tb` 下载并校验当前 Git 提交，
  通过后原子切换（当前版自动成为上一版）。
- **恢复上一脚本版本**：一键回到上一个可用版本。
- 所有更新都只发生在用户数据目录，失败时保持当前可用版本不变；
  程序不在启动时自动联网同步。完整运行时随发行捆绑，与脚本同步无关，
  同步/回退后任务同样可直接运行。
- 同步会校验全部受支持任务脚本（日常 + 限时活动）都存在且语法正确；
  上游若移除某脚本，同步会被拒绝并保留当前版本。

## 常见故障

| 现象 | 处理 |
| --- | --- |
| 提示“未找到内置 ADB” | 确认 `platform-tools\adb.exe` 在程序目录内；重新安装。 |
| 提示“缺少运行组件 / 未找到数据运行时” | 打开主界面 **维护与更新 ▾ → 下载中心** 下载必需组件（首次联网约几百 MB）；若下载失败可重试。 |
| 下载中断/失败 | 点该组件“重试”；下载文件先进临时目录，校验通过才启用，不会留下半成品。 |
| 设备 `unauthorized` | 解锁手机，接受 RSA 授权后重新检测。 |
| 设备 `offline` | 重插数据线，关闭其它占用 ADB 的工具。 |
| 运行中被自动停止并提示“设备已断开” | 手机被拔出/离线/未授权；程序已自动停止整个队列。重新连接后再次开始。 |
| 限时活动任务失败 | 多为活动已过期/页面改版，属预期；会如实显示失败。 |
| 首次运行任务较慢 | 首次加载 torch/easyocr 模型需要时间（CPU 推理），属正常。 |
| 运行中提示验证码/登录/支付 | 脚本会暂停并如实报告，请人工处理，程序绝不绕过。 |
| 第二次启动无反应 | 单实例设计：第二次启动会激活已打开的窗口。 |

## 限制与声明

- 不支持无线 ADB、多手机并发、无人值守定时、自动登录、验证码处理、静默更新 EXE。
- 上游活动脚本可能因淘宝/闲鱼/支付宝 App 改版而失效——失败会如实显示，不保证仍适配实时页面。
- 本软件为学习/研究用途的非官方封装，与淘宝、闲鱼、天猫、支付宝等无关。

## 卸载

### 轻量安装版

在“设置 → 应用 → 已安装的应用”中卸载“Coin11助手（轻量版）”，或运行安装目录里
的卸载程序。卸载向导会询问是否删除用户数据；**默认保留**
`%LOCALAPPDATA%\Coin11Helper`（脚本、日志与已下载运行组件），便于日后重装继续用；
勾选“删除我的数据”才会一并清除。

### 完整运行时离线版（解压版）

1. 删除程序所在目录；
2. （可选）删除用户数据目录 `%LOCALAPPDATA%\Coin11Helper` 以清除设置、日志与
   运行组件；

本程序不开机自启、不做系统级注册（无托盘驻留）。两种形态都不会在卸载时擅自删除
`%LOCALAPPDATA%` 下的脚本、日志与运行时，除非用户明确选择删除数据。
